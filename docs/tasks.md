# SDVC 웹서비스 Codex 전환 — 작업 분해

작성일: 2026-09-19 · 상태: **사용자 승인 완료** · Analyze 보완 승인 완료 · Phase 1 진행

## 역할 매핑

- 수강생 = 기존 DB/코드의 `role='developer'`이다. 기존 값을 유지하고 새 화면에서는 수강생으로 표시한다.
- 개발자/운영관리자 = 기존 DB의 `role='admin'`과 `admin_tier`이다.
- T013~T022는 이 매핑을 고정하는 권한 테스트를 포함하며, `developer` 문자열만으로 관리자 접근을 허용하지 않는다.
- `.sdvc/session-checkpoint`는 플랫폼 개발 세션용이다. 수강생의 웹 재접속은 T032~T036의 DB 기반 지속 작업으로 검증한다.

## 작업 규칙

- 기능 하나를 DB·서버·화면·검증까지 완성하는 버티컬 슬라이스로 구현한다.
- 각 기능은 RED(의미 있게 실패하는 테스트) → GREEN(최소 구현) → REFACTOR(정리 및 회귀검사)를 별도 커밋으로 남긴다.
- `[P]`는 서로 다른 파일과 독립된 의존성을 사용해 병렬 수행 가능한 작업이다.
- 외부 공급자 계정·유료 리소스·운영 데이터는 명시적 승인 없이 생성하거나 변경하지 않는다.
- 완료 판정에는 실제 명령, 종료 코드, 로그, 코드·테스트 버전이 필요하다.
